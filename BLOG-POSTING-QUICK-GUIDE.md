#### **#5: Medium** ⭐⭐
**URL:** `medium.com/@livingwitharthritis`

**Steps:**
```
1. Create Medium account (free)
2. Wait 24 hours after publishing on your blog
3. Paste full blog post into Medium editor
4. Add at the top:
   "Originally published on Living With Arthritis UK →
   https://livingwitharthritis.org.uk/blog/[slug]"
5. In settings:
   - Set "Canonical URL" = your blog URL
   - This tells Google: "Your site is the original"
6. Publish on Medium
7. Medium readers click through to your blog (traffic!)
```

**Canonical URL ensures Google ranks YOUR site, not Medium's copy**

**Traffic impact:** 100-500 visits per post

## **COMPLETE CONTENT CHECKLIST** (Before You Hit Publish)

```
BEFORE WRITING:
□ Keyword research (what are people searching?)
□ Outline created (H1, H2s, sections)
□ Competitor analysis (what do #1 rankings have?)

WHILE WRITING:
□ 2000+ words (compete with Arthritis UK)
□ H1 with keyword
□ 3-5 H2 subheadings
□ 8-10 FAQ questions
□ 3-5 internal links to other guides
□ Video embed OR infographic
□ Author byline (Louis Maxwell, HCPC)
□ "Last reviewed" date

IMAGES:
□ Featured image (1200x630px, .webp)
□ Alt text on all images
□ Compression (<200kb per image)

SEO METADATA:
□ Meta title (60 chars, keyword, compelling)
□ Meta description (160 chars, includes CTA)
□ og:title, og:description, og:image
□ Schema markup (MedicalPageSchema)
□ URL slug (lowercase, hyphens, 50 chars max)

CODE QUALITY:
□ npm run lint (passes)
□ npm run seo:schema (valid JSON-LD)
□ npm run build (no errors)

TESTING:
□ All links work (internal + external)
□ Mobile responsive (test on phone)
□ Video embeds play
□ Spell check (Grammarly or manual)
□ Grammar check
□ Read aloud test (sounds natural?)

SOCIAL PREP:
□ Featured image created
□ Instagram carousel slides designed
□ Instagram reel script written
□ Facebook copy written
□ Email subject line written
□ Hashtags prepared (#ArthritisSupport #ExerciseForArthritis)

DEPLOYMENT:
□ File created: src/pages/blog/BlogTitle.tsx
□ Added to blog index
□ Deployed to Lovable
□ Verified live on website
□ Submitted to Google Search Console
```

### **Best Times for Each Platform**

```
INSTAGRAM:

- Wednesday 7pm (people browsing in evening)
- Friday 2pm (lunch break scrolling)
- Peak: 8am, 1pm, 7pm

INSTAGRAM REELS:
- Wednesday 7pm, Friday 2pm, Sunday 8pm
- Reels get 67% more engagement than photos

EMAIL:
- Monday 8-10am (high open rates)
- Send consistently same time = better opens

MEDIUM/LINKEDIN:
- Tuesday-Thursday (people consume long-form mid-week)

REDDIT:
- Tuesday-Thursday (when people browse)
```
