# Contributing to Living With Arthritis

Thanks for your interest in contributing! We welcome issues, feature requests, and pull requests.

How to contribute

1. Fork the repository and create a branch for your change: `git checkout -b feat/my-feature`.
2. Run the project locally and add tests if applicable.
3. Keep commits focused and add a descriptive commit message.
4. Open a pull request with a clear description of the change and link any related issues.

Development

- Install dependencies: `npm ci`
- Start dev server: `npm run dev`
- Build: `npm run build`
- Lint: `npm run lint`

Pull request checklist

- [ ] Code builds locally
- [ ] Tests added or updated (if applicable)
- [ ] Linting passes
- [ ] Documentation updated (README or docs)

Code style

- This project uses TypeScript and Tailwind CSS. Please follow existing coding patterns and keep changes small and focused.

Security

If you discover a security vulnerability, please do not open a public issue. Contact the repository owner directly and privately.
