# Contributing

See README.md. Branch from main, open a PR, do not commit .env.local.

## Delivery to main

Lovable and Instinct changes are delivered through `main`, not left only on
working branches. Open a pull request and merge only within the owner's current
approval after required checks and independent review pass on the final head.
Preserve newer work when reconciling old or conflicting branches. Keep branch
protections, required checks and security controls enabled. See AGENTS.md for
the full main-delivery rule and separate spending/access restrictions.
