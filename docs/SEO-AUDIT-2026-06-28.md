keep re-surfacing because the scanner can't see the intent.

### 2. Four stub pages missing OG/Twitter meta — **low priority**
- `src/pages/AiHub.tsx`
- `src/pages/LocalizedHome.tsx`
- `src/pages/LocalizedOsteoarthritis.tsx`
- `src/pages/stubs/index.tsx`

Add a `<SeoHead>` block to each. ~10 min of work.

### 3. JSON-LD warnings on 13 hub pages — **cosmetic**
`/sources`, `/ai-citations`, `/ai-guidelines`, `/accessibility-for-ai`,
`/living-with-arthritis`, `/arthritis-mental-health`, the 5 `/guides/*`
pillars, `/exercises`, `/arthritis-flare-ups`.

Single missing field per page (typically `image` on the WebPage block).
No Google validator errors — only Semrush's stricter "recommended"
check would flag.

### 4. Lighthouse: hero LCP slow on published build
Add explicit `width`/`height` + `fetchpriority="high"` and drop
`loading="lazy"` from the homepage hero `<img>`. Needs a publish to take effect.

### 5. Accessibility: a few low-contrast text nodes + "Learn more" links
Replace `text-muted-foreground/50` with `text-muted-foreground` and
rename generic anchors in `src/components/landing/AboutArthritisCards.tsx`
(e.g. "Read the osteoarthritis guide" instead of "Learn more").

### 6. Semrush content opportunity
Add `/blog/turmeric-vs-ginger-for-arthritis` — builds on the natural
anti-inflammatory cluster that's already ranking.
