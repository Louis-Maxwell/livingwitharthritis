## On-page trust pattern (copy from Cleveland/Mayo *structure*, not claims)

Every Champion / condition / medicines page:

1. Byline: author + reviewer name + credential IDs.  
2. Dates: published + last clinically reviewed.  
3. Disclaimer: educational, not personal medical advice; seek GP/FCP/rheumatology.  
4. Citations: NHS/NICE/primary literature — visible references block.  
5. Update trigger: guideline change or incident.
